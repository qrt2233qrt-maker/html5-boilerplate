# Pizza Rita — ChatGPT prompt for ALL the pizzas

All 21 pizzas (4 specials + 17 menu pizzas), made from your real pizza photo so the whole pizza menu matches.

## How to use

1. Open **ChatGPT** and start a new chat.
2. **Attach your real pizza photo** (`real-pizza-a.jpg`, the round one with the puffy crust).
3. Copy the **master prompt** below and send it.
4. ChatGPT makes the pizzas one by one. After each image, type **"next"**.
5. **Download each image** and name it with the file name ChatGPT gives (e.g. `pizza-01-hawaiian.png`).
6. Come back to Claude and **upload the images** (all at once or in batches). They will be made round, given the puffy crust and turned into 1200×1200 delivery-app pictures.

> Tip: ChatGPT can slowly drift away from your photo over a long chat. After about 7 pizzas, start a **new chat**, attach the photo again, paste the master prompt, and write "continue from number 8" (or whichever number is next).

## Master prompt (copy everything inside the box)

```
You are making menu photos for my pizza restaurant, Pizza Rita.

I attached a real photo of one of my pizzas. Use it as the reference for EVERY image:
- Keep the exact same round pizza with the puffy, golden Neapolitan crust and charred spots

- Keep the same size and position of the pizza in the frame
- Change ONLY the toppings (for the calzone, fold the same dough into a calzone)
- Square image (1:1), realistic food photography, no text, no logo, no watermark

Make these 21 pizzas, ONE image at a time. After each image, tell me its file name and wait until I write "next":

SPECIALS
1. special-margherita — tomato sauce, melted mozzarella and a few fresh basil leaves
2. special-pepperoni — lots of pepperoni slices on double mozzarella

PIZZAS
```

## If ChatGPT drifts away from your photo

Start a new chat, attach the photo again, and send this for just the one pizza you need. Replace `[TOPPINGS]` with the toppings from the list above:

```
Using this photo as reference, keep the exact same round puffy Neapolitan crust, the same white printed fast-food paper, the same dark table, camera angle and lighting. Change only the toppings to: [TOPPINGS]. Realistic food photo, square, no text.
```

**Fixing one image:** reply to ChatGPT with "keep everything the same, but …" (for example "…add more pineapple" or "…make the crust more golden").
