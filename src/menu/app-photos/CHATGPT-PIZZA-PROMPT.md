# Pizza Rita — ChatGPT prompt for the 7 missing pizzas

## How to use

1. Open **ChatGPT** and start a new chat.
2. **Attach your real pizza photo** (`real-pizza-a.jpg`, the round one with the puffy crust).
3. Copy the **master prompt** below and send it.
4. ChatGPT makes the pizzas one by one. After each image, type **"next"**.
5. **Download each image** and name it with the file name ChatGPT gives (e.g. `pizza-01-hawaiian.png`).
6. Come back to Claude and **upload all 7 images**. They will be made round, given the puffy crust and turned into 1200×1200 delivery-app pictures.

---

## Master prompt (copy everything inside the box)

```
You are making menu photos for my pizza restaurant, Pizza Rita.

I attached a real photo of one of my pizzas. Use it as the reference for EVERY image:
- Keep the exact same round pizza with the puffy, golden Neapolitan crust and charred spots
- Keep the same white printed fast-food paper under the pizza
- Keep the same dark table, the same top-down camera angle and the same natural lighting
- Keep the same size and position of the pizza in the frame
- Change ONLY the toppings
- Square image (1:1), realistic food photography, no text, no logo, no watermark

Make these 7 pizzas, ONE image at a time. After each image, tell me its file name and wait until I write "next":

1. pizza-01-hawaiian — turkey slices and pineapple chunks on melted mozzarella
2. pizza-09-free-choice — pepperoni, mushrooms, green peppers and black olives on melted mozzarella
3. pizza-12-vegetarian-delight — red onion, mushrooms, green peppers, sweet corn and fresh tomato slices on melted mozzarella
4. pizza-13-vegetarian-hot — red onion, mushrooms, jalapeño slices, green peppers and fresh basil leaves on melted mozzarella
5. pizza-15-mix-shawarma — sliced chicken shawarma and sliced beef shawarma on melted mozzarella
6. pizza-16-shawarma-meat — sliced beef shawarma on melted mozzarella
7. pizza-17-shawarma-chicken — sliced chicken shawarma on melted mozzarella

Start with number 1 now.
```
