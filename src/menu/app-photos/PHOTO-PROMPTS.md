# Pizza Rita — photo prompts for the rest of the menu

Paste each prompt into your image tool (the one you used for your posts, or Canva / Adobe Firefly).
Choose **landscape 3:2** where possible. Save each result with the file name shown, then send them all
back so they can be turned into the 1200×1200 delivery-app pictures.

Every prompt ends with the same style so the whole menu matches the photos you already have:

> **STYLE:** professional food photography, dark rustic wooden table, warm moody lighting, deep brown tones, fresh ingredients arranged around the dish, appetizing, sharp focus, no text, no logo, no watermark
